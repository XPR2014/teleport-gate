# Teleport Gate 传送门方块模组

**A practical Minecraft Fabric mod that adds customizable teleport blocks for intra\-dimensional fast travel \& multiplayer use\.**

**一款实用的 Fabric 模组，添加可自定义传送方块，实现同维度快速传送，完美适配多人联机。**

---

## ✨ Features 功能特性

### English

- Add namable teleport blocks for free intra\-dimension travel

- Full multiplayer support, all players share dimension teleport points

- Built\-in search bar for quickly filtering teleport points

- Teleport cooldown system to prevent frequent spamming

- Beautiful teleport particles \& sound effects on successful teleport

- Duplicate name verification to avoid naming conflicts

- Independent storage of teleport points for each dimension

- Automatic timed data auto\-save, prevent data loss from game crash/exit unexpectedly

- No cheats or operator permissions required to use

- Automatic remove invalid teleport points when blocks are destroyed

### 中文

- 新增可自定义命名的传送方块，支持同维度自由快速传送

- 完美支持多人联机，全服玩家共享对应维度传送点

- 内置搜索框功能，快速筛选目标传送点

- 自带传送冷却机制，防止高频恶意传送刷屏

- 传送成功触发专属粒子特效与音效，交互体验拉满

- 传送点重名校验机制，杜绝命名重复冲突

- 分维度独立存储传送数据，维度数据互不干扰

- 定时自动存档机制，杜绝闪退、意外退出导致的数据丢失

- 无需开启作弊、无需OP权限，普通玩家即可使用

- 破坏传送方块后自动清理对应传送点数据

## 🔧 Installation 安装教程

### English

1. Install Fabric Loader and Fabric API for your game version

2. Put the mod JAR file into the `mods` folder of your Minecraft client/server

3. Restart the game/server to complete installation

4. Both client and server need to install this mod for normal use

### 中文

1. 安装对应游戏版本的 Fabric 加载器与 Fabric API 前置模组

2. 将本模组 JAR 文件放入客户端/服务端的 `mods` 文件夹

3. 重启游戏或服务器即可正常使用

4. 客户端、服务端必须同时安装本模组，否则无法正常运行
